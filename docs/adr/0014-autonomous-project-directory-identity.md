# ADR 0014：自主项目用根目标 ID 确定目录归属

- 状态：已采纳（2026-11-22）
- 契约与验收：[设计 §8.2](../DESIGN.md#autonomous-project-dirs)

## 背景

原命名从目标文字硬截 24 字符，仅在另一个活跃目标已绑定同名目录时加后缀。完成的目标、无绑定目录以及同前缀的历史目录都可能被误认；索引和归档又各自按名称猜归属。更换命名算法不能牺牲断点续作。

## 决策

- 将显示标题与目录身份分开。新项目使用「简短 ASCII 标题 + 稳定根目标 ID」，而不是让模型起名或让标题承担唯一性。保持标准库运行和同一目标树共用一个主工位。
- 沿用现有每 Agent 持久映射和单写者，不引入新库、外部命名服务或迁移脚本。已有明确绑定原地复用；盘上同名但无绑定的内容默认不接管、不移动。兼容历史目录名不等于授权按名称推断归属。
- 已绑定主工位不可用时暂停并提示，不自动分配第二个工位。索引与归档只信任明确绑定。现有文件存储和工作区路径检查的跨进程、路径替换边界不变。

# ADR 0009：对话和后台共用身份，不共用长等待

状态：采纳，M70 已本地实现。承接 ADR 0006 的单 Run 保证和 ADR 0008 的离线可查原则；替换后者的普通聊天争用长锁限制。

## 决策

- 保留会话/调度准入锁和已有安全检查。另以短状态护栏保护确实重叠的内在状态操作，背景等待模型和可独立执行的工具时释放该护栏。对话按 Agent 串行提交，推理不在护栏中，不让模型生成的对话直接操作任务或工具。
- 以脱敏结构化事件给出后台工作的外部事实，近期事件有界、快照按 Agent 隔离；终态及恢复仍以持久 Run 与检查点为准。采用轻量定期快照读取，暂不引入 SSE、推理流或第二个对话 Agent。
- 自动心跳尊重主模型当前绑定的冷却时间，拒绝/超时要区分于目标验收失败。主/快和不同接入配置的熔断相互隔离；短计划成功不掩盖主模型反复超时。不暗中换模型、加钱或重试未知外部工具。
- 同谱系各阶段通过有界文件索引交接；现有项目不移动、不试图自动合并冲突。源码、构建验证和可用交付分别报告。

不采用「每条路径各自锁住同一个可变 Agent」或「后台正忙只能排队回执」，前者不保护共享写入，后者无法满足正常交互。接口、验收和现场诊断见 [总设计 §14.6](../DESIGN.md#concurrent-dialogue-live-work)。

# ADR 0021 · Electron 与 Web 单源控制台

状态：采纳（2026-11-22）。更新 M22 当时只提供 WKWebView 的选择，保留原生壳与零依赖 Web，不将 Electron 变成核心依赖。

## 决策

- Electron 只负责窗口、本机服务发现及托管。它直接运行同一个 `proto/web/index.html`，使用同一服务和鉴权 API；不复制页面、轮询、功能入口或数据，不能在壳中另实现公司、审批、舰队等业务。
- 正常启动的 `proto.web` 以同一数据目录现有实例锁约束写者，并在目录中的私有运行区发布绑定规范目录的一次启动连接材料。Electron 用挑战回签验证回环端点并固定主页面来源，不扫描端口、不把真实令牌放进 Electron 页面、托管 Python 参数或日志。没有可信记录才尝试在该数据目录启动；只连接模式不启动。
- Electron 只关停本次启动的进程，使用正常中断而不强杀；接入现有 Web 或系统服务时，退出桌面不折断后台自治。重连不另建舰队，不自动重启已有 Web。服务按原参数重启后，浏览器刷新、Electron 用菜单重连读取新的回签密钥，两端加载同一服务版本。
- 选用独立的可选 npm 包，锁定 Electron 稳定发行版，按官方安全清单禁用 Node 集成、保留隔离和沙盒，限制权限、窗口和导航。实时活动等功能验收继续测 Web；壳的协议、拒绝路径和真实窗口另测。Electron 引擎升级需要重装锁文件所指定的依赖，不等同于控制台功能升级。

不选独立桌面前端（会丢失新功能和状态语义）、按端口探测并盲发主人令牌（可能对上其他服务）或内嵌第二个数据写者。流程、权限边界和验收见[总设计](../DESIGN.md#electron-console)。

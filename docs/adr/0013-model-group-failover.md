# ADR 0013：模型组与有界回退

- 状态：接受，已实现并通过 M76 回归
- 日期：2026-11-22
- 契约：[总设计 · 模型组](../DESIGN.md#model-groups)

## 背景

模型目录可以热切换单一接入，但改选需要主人操作。自主工作不能因一个供应商在冷却或响应异常就放弃已有进度，也不能为找可用模型制造请求风暴。

## 决策

- 用有序组引用持久目录中的接入。现有主/快角色可选组或单模型；保持所有 Agent 的共享配置与旧选择兼容。
- 在 Agent 的受守卫模型调用边界选择候选。固定一次调用的组和成员快照；可回退的传输、容量或接入故障只允许再派发一次，每次走原额度、准入和结算。不在低层 HTTP 客户端重试，也不重放执行步骤。
- 复用按接入的熔断与共享压力治理。组请求额外守同源并发和持久 429 冷却，不通过别名、路径或不同密钥规避同源限流。政策拒绝、请求不合法、权限、审批和额度不是可用性信号。
- 活动记录实际参与的模型；没有可用候选则使用既有等待和安全续作，不另起 Run 重做工作。

## 未采纳

- 逐一探活、询问所有候选或失败后无限切换：增加成本与压力，可能触发重复工作。
- 自动全目录切换、按价格分流或跨组跳转：不符合主人的数据边界与明确选择。
- 每个 Agent 保存独立配置或把回退写进任务：扩大配置范围，容易丢失额度门、会话与热切换的一致性。

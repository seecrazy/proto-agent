# ADR 0016：自主想法的多样性筛选与独立批评

- 状态：已采纳
- 接续：[ADR 0002](0002-goal-forge-and-local-verification.md)

## 背景

旧 GoalForge 用词面相似和模型自报可行性挑一个高分想法，再由交付验收检查做出的东西。两者都不能回答：现有方法具体在哪失效、什么时候该放弃、是否有区别足够大的替代方案。

## 决定

1. 在 GoalForge 内加「取材与原文拆解 → 跨素材重组 → 结构化候选 → 最大多样集合 → 隔离批评与修正」；仍只把一项合格提议播种到 `GoalTree`，不增设执行队列。原学习笔记晋升只是已有内容的可见性审批，与创新提议分开，不能代替立项或记为 yield。
2. 默认使用版本化的结构语义 embedding：固定词表中的方法、问题、预期价值、角色映射到稀疏向量，程序计算余弦距离；不用字词重合假装语义，也不要求舰队配新的网络 embedding 服务。它是粗粒度且受标签准确性影响的第一版，不等同于训练出的句向量。代码按用户给定的**距离** `< 0.80` 判重复；不把 `0.80` 偷换成余弦相似度阈值。
3. 评议用单独的无状态批评 Agent 实例，无执行工具、无目标写入，与生成上下文分离；可走不同模型角色，但不同角色不保证不同底模。评议错漏、修正后新增违规、缺少证据路径都不放行。所有模型调用走现有自主预算、退避及取消；上限是每轮五次创意调用，可选一次目标分解。
4. `EXPLORE` 为默认，`EXPLOIT` 只试最高分未立项候选的一个可回退首步，`FINAL_GAMBLE` 只对合格且不重复的候选比较二点预测方差和新颖度。姿态不是权限，也不改验收。

## 后果

- 可看见过筛数量和拒绝原因，空集是合法结果。被选想法保留首步、适用范围和证伪条件；这些是待验证假设，不等于已验证用户需求。
- 历史库随单 Agent 保留，不共享给同事；常规审批、本地证据验收、现有目标与人工指派不迁移。刻意不引入真实用户实验自动化、外部向量服务或神经模型下载。

# ADR 0008 · 控制台活动问题不等待 Agent 写锁

状态：采纳（2026-11-21）

## 背景

后台 Run 持有目标 Agent 的单写者锁等待模型响应。普通聊天在三秒后返回 `agent_busy`，但页面没有展示该错误；一句「在干嘛」也要求取得写锁和走模型，主人看不到反馈。

## 决策

- Web 聊天完整匹配有限的活动短问句时，执行与活动卡相同信任级别的本地只读查询。复用内存执行标记和既有 `running` Run，不新增持久状态。
- 保留普通聊天的锁、返回结构和超时行为，前端显式展示忙碌和发送失败。不排队、不自动重发，不将请求失败解释成模型已回答或任务已执行。

## 取舍

给任意聊天免锁会破坏对话、记忆与后台任务的单写者约束；由模型识别状态查询又会依赖本轮失败的链路。短句匹配可离线给出真实状态，代价是释义和复合问句仍需正常聊天。界面应明确没有发现后台工作不等于能证明模型连通。

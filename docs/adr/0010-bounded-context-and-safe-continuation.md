# ADR 0010：工作历史有界投影，执行按回执续接

状态：采纳，M71 已实现。

- 持久历史、项目文件、目标验收与发给模型的上下文分层。不做必需的模型摘要调用；用确定性进度投影保住已落盘路径和已记录检查，窗口压力下牺牲可重读的输出，不牺牲规则。固定区超限明确停下，而不是裁掉审批或项目约束。
- 分离「决策未派发」「工具已确认返回」「工具可能已产生未知效果」。在第一次和第二种情况下用原会话动作/回执续接；第三种停下核对。键和步数保持不变；重试不突破当下授权或额度。不能用存在某个文件来推断任意工具已经执行，也不以重新发送所有工作取代续接。
- 调度器回收进程时只自动续接具有新版且有效证据的会话；异常代码不在同一进程中自激重试。模型故障允许有界退避和仅安全点的人工恢复。保留单实例、文件文档和 SQLite 的现有边界，不引入分布式事务或新模型提供商依赖。

完整状态、边界和验收见[总设计 §15.4](../DESIGN.md#durable-work-continuity)。

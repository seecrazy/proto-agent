# ADR 0007：只读计划、主人定版与交付证据

- 状态：接受（M68）
- 日期：2026-11-21
- 方案与验收：[总设计](../DESIGN.md#reviewed-task-plans)

## 背景

PROTO 已有持久目标、自治授权、Run 调度、工具审批和项目交付验收。直接指派的快速规划却是模型内部建议，主人看不到拟做的事与验收，也不能先批计划再派发。普通任务的模型语义验收与 M67 项目固定产物验收不是同一机制。

| 同类产品的公开机制 | PROTO 取舍 |
|---|---|
| [ZCode Goal](https://zcode.z.ai/cn/docs/goal)：目标持续推进，完成要有证据，不靠计划或自述 | 沿用 GoalTree 和预算；先把明确声明的文件变化作为普通任务的硬门，不移植自动跨轮续跑 |
| [Codex AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：目录逐层加载，`AGENTS.override.md` 优先 | 沿用 M63 范围、快照和上限；增加目录内覆盖与计划规则清单，不读取宿主或用户全局规则 |
| [Claude Code 权限模式](https://code.claude.com/docs/en/permissions#permission-modes)：只读规划与执行分阶段 | 计划调用不开放工具；主人批准当前摘要才创建执行 Run，批准计划不是批准工具 |

## 决策

1. **计划是不可变的审阅材料，不是授权。** 用同一个调度器与预算做 `plan`；`planned_task` 引用成功计划和摘要。审批事务幂等，不覆盖原计划，不引入第二种会话/执行器。
2. **批准的是确定的任务、范围、规则和验收。** 计划绑定 Agent、工作区、输出基线；执行前重新核对。人设和权限使用执行时的现行值，执行中的工具照常由 Router 和原审批接管。
3. **先核对硬证据，再判语义。** 可选输出是少量工作区文本文件。记录路径和摘要，不把文件内容带进规划或运行审阅。未声明文件则只有原语义验收；非空变更证据不替代测试或正确性判断。

不迁移数据，不另建计划表，不接管 M67 的项目交接，也不调用其他 Agent CLI。技能包、任意钩子和工作树隔离留待独立权限与宿主隔离评审（见 [D12](../DEBT.md)）；不给本功能的路径/摘要检查赋予沙箱含义。

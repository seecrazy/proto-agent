# ADR 0019：中文对话独立复验，不交给生成端自评

- 状态：已采纳
- 实施契约：[总设计 §13.8](../DESIGN.md#natural-dialogue)

## 背景

普通对话原来只在系统提示里说「简短自然」，生成稿未经检查就返回并进入对话历史。提示词不能保证模型少写套话；再让它自评又增加成本，并且容易引入无依据的改动。用户提出的扫描、诊断、局部改写、复验应分职责，不应增加第二个生成模型。

## 决定

1. 用随包发布的版本化 JSON 原创规则和 Python 标准库实现扫描。扫描层无模型、网络或可执行第三方脚本。未核实 `dsh-plugin-nature` 的准确发行源，不绑定该依赖或声称已经覆盖其文体。内置多个文体，只默认处理人机对话的完成稿。
2. 处方选择和改写分离。以原文坐标拼接受信的裁剪或标点补丁，拒绝不在命中句、有保护片段、引入正文字符或无法安全改写之处。文风诊断不限于可自动修复的项；语义依赖上下文时宁可放弃，不以更文学或更简短换取事实准确。
3. 采用更严退出条件：命中下降、无新增事实且无「需要改写」三者同时满足。可保留低严重度诊断；最多两轮，从原稿重试。扫描不完整或复验失败按未处理交付，不能把中间稿写进历史。结构化结果用于只读工具和回归，普通接口及记忆只收到最终正文；运行日志仅含非内容的计数和状态。
4. 在 `ProtoAgent` 的共享人类对话出口接入，保持现有身份快通道、前后台并行和幂等性。不把改写器升级成全局拦截器；主动工作报告、角色写作、代码和需要原样引用的文本不受这套聊天默认值支配。

## 取舍

本地启发式只能识别已定义信号，不能辨别作者。既有的否定、专有名词、格式和个人习惯比降分重要。开放任意正则或模型自由改写会损害可预测性和验收，当前只维护受信的规则与保守处方；扩大覆盖应先补充误报样本。

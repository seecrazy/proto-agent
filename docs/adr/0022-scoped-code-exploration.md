# ADR 0022：大仓库按符号定位，读源码的上下文与主执行会话分离

状态：采纳。实施与验收见[总设计 §7.3.1](../DESIGN.md#large-code-context)。

- 保留 M71 的固定区、原始回执与安全断点。在发出**下一次**决策前按实际待发材料算预算；压力下确定性地把历史换成回执、文件位置和少量近期观察。宁可不发也不裁项目规则。不依赖上一请求的 usage，不额外调用模型来压缩。
- 索引是每个工作区自己的、惰性构建的有界内存缓存。分页解析文件声明，按标识符、路径和文档词排序；只有显式读取才取正文。不使用外部向量服务、不在源码目录写索引、不声称能推断跨语言调用或数据流。
- 将内置探索器作为原 Router 的只读工具。独立短上下文、固定工具白名单、有限轮次，继承本次执行的预算与停止条件；只把短结论和宿主记录的位置返回主会话。外部编码 CLI、舰队通信、普通对话和执行授权不变，不在后台创建另一条可写任务链。

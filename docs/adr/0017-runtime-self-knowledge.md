# ADR 0017：运行时自我事实独立于人设和对话记忆

- 状态：已采纳
- 实施契约：[总设计 §13.7](../DESIGN.md#grounded-self-knowledge)

## 背景

原对话提示词有角色文本和最近记忆，但没有当前时间、创建时间或舰队名称。独立运行早于被收编，注册表时间有两个含义；直接拿它算年龄会把旧成员说年轻。启动或停机不应抹去自身历史。普通回复受模型健康和对话锁影响，不能作为问询这类事实的前提。

## 决定

1. 新增按 Agent 的生命周期记录，明确区分创建时间和只够证明「至少从何时存在」的证据。旧托管记录用创建时间，旧外部记录优先从首次已校验的原始锚定初始化恢复，不拿最新所有者锚定、收编或文件时间当生日。旧证据不足时持久保存下限，并明说不确定。只验证用到的首条审计，不为每次问询扫描审计链。
2. 墙钟用于创建和存在时长；单调钟用于本次加载。停机期间照样增长的是前者，而非实际工作时间。暂不建立跨进程在线或工时账本。
3. 名称、舰队 ID、人设、任职和自治阻断分别沿用原权威状态。Web 身份视图与离线问答共用运行时投影；高置信的独立事实问题沿用只读问询方式，不发模型、不创建对话记忆。含其他任务的输入继续由普通对话处理。
4. 给对话和每步执行决策补一段短的实时事实，作为单独的数据块，不改变模型的系统角色和任务协议。不把随时间变化的数据写入冻结的任务上下文，亦不改变工具授权、验收或既有活动证据。

## 后果

年龄不用重复写入、压缩记忆或加模型成本。旧实例在使用原数据目录正常重启后渐进补录；证据有缺失时，不能保证回推出完整历史。控制台不自动操作真实任务。

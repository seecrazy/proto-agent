# 运行时不变量审查与修复设计（2026-11-21）

> **历史审查与验收记录。** 当前运行时协议、预算、审批恢复、工作区及剩余边界已归并至 [PROTO 总设计](../DESIGN.md)；本文件保留 M62 修复清单与验证证据。

## 1. 目标与非目标

目标是核对当前设计承诺与实际执行路径，优先修复会突破授权、预算、工作区边界或错误宣告完成的问题。保留已有 M61 未提交实现，不重写五层架构，不增加运行时依赖，不操作真实账户、线上服务或用户项目产物。

本轮不实现多进程事务、完整 Agentic 循环跨重启续跑、Linux 沙盒适配或新的 UI。未覆盖的边界登记在 DEBT，而不是以测试通过代替能力声明。

## 2. 架构分析与证据

- 优点：L1 安全策略不依赖模型分类；DocumentStore 可替换；GoalTree、质量门、执行器、工具族分层清楚；测试可在不访问外网的情况下覆盖主流程。
- 问题集中在层间接线，而非缺少抽象：同一预算池没有贯穿验收/方法策展/Router；审批决定与检查点状态不一致；工作区对象替换没有更新已注册闭包。
- `ProtoAgent` 同时承担组装、任务、目标、计账和 UI 投影，存在直接写 GoalTree 私有存储等耦合。本轮先修契约，不进行高风险的大规模拆类。
- 审查基线：Python 3.9.2，`python3 -m pytest -q` 为 **653 passed, 2 skipped**。项目 `.venv` 未安装 pytest，验证使用现有系统 Python；不修改用户环境。

## 3. 用户流程

1. 主人任务使用 owner_tasks；自主目标使用 self_initiated；两者的计划、工具、验收和辅助生成保持同源预算。
2. 模型必须提供合法工具对象或显式布尔 done；格式错误只返回纠正提示，不冒充成功。
3. 可见/不可逆动作先保存审批与原步骤。拒绝终结该检查点；批准后认领原步骤，再走同一执行、参数过滤和审计路径。
4. 切换项目根目录后，读取、写入、命令 cwd、质量门与项目索引全部使用新工作区；旧产物不迁移、不删除。
5. 完成目标仅允许 active → done；dropped 不得复活；重复请求不重复奖励。父级全部完成时仅通知一次。

## 4. 数据与状态模型

- 检查点沿用现有 state 文档：等待态有 waiting_for；认领后移除 waiting_for，写入 status=resuming；终态写 completed/denied。旧等待态检查点继续可读。
- 不声称外部副作用 exactly-once：认领后崩溃时禁止自动重放，需主人核对。现有单写者加 Router 恢复锁防同进程并发恢复。
- 预算分为请求前预留与响应后结算。实际发生的用量必须入账；超出余量时允许出现负余额表达欠额，并阻止该池下一次调用；全局欠额触发熔断。估算多收部分退回但不超过上限。
- 预算读/改/退回/重置使用同一 RLock，读取前确保周期有效。配置使用独立副本；已保存上限跨日生效。
- 主人显式充值重置预算熔断，不改变 LLM 故障熔断器；批量改上限必须全量校验后在一次资源锁内提交。
- GoalTree 不改变持久 Schema；读取集合时锁定快照，写入与完成/丢弃继续使用资源锁。

## 5. 关键交互、边界与错误处理

- 拒绝审批后再次批准：返回 not_paused/denied，绝不执行原工具；失败恢复也不得重放已认领动作。
- 工具参数过滤不丢弃 **kwargs 接收的参数；Agentic 观察使用真实工具结果，不使用“忽略未知参数”的附注冒充结果。
- 无验收定义仍保留既有“完成但未验证”兼容路径；不把它描述为验证通过。非 JSON 决策不再走此路径。
- 验收字段只接受非空字符串；验证器 verdict=pass 但 missing 非空或类型错误时失败关闭。
- 超大单行分页仍有字符上限，并显式标注截断；大文件后续行必须可访问。
- 网页抓取限制针对内置传输器；测试注入的 fetch 是可信宿主接口，不是生产网络策略替代品。域名白名单不等价于 DNS/IP 级隔离。
- 目标分解期间主人丢弃目标：LLM 返回后重新检查状态，不得添加新的活跃后代。
- 不使用真实数据目录执行回归测试；临时工作区和本地 HTTP 假服务覆盖路径与网络行为。

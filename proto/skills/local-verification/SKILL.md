# 本地验证

1. 在任务目录调用 `inspect_build`，读本项目的说明、清单、锁文件和测试配置。本机存在解释器不代表安装了验证模块，不同目录/包管理器不能互换。
2. 先做最小可复现检查。Python 优先用 `python3 -m pytest` 指向相关测试；需要打包时用项目已有构建配置。Node 优先用声明的包管理器和 `package.json` 现有脚本（先确认脚本确实验证目标）。Swift Package 分别运行 `swift build` 和 `swift test`。用数组 argv；不要在命令里假造产物或测试报告。
3. 测试失败先区分缺依赖、零测试、超时和断言失败。保持相关检查的原命令；修复后重跑，明确记录退出码以及未验证的范围。不要自动装包或跑未审查的网络命令。
4. 如果是界面任务，构建成功不能替代实际点击、截图或设备验证。本运行时没有这样的证据时请明确「未验证」，别编造结果。
